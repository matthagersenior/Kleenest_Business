# Four Seasons Hotel St. Louis — Kleenest Specific Offer v10

_Source artifact: Kleenest_Four_Seasons_Specific_Offer_v10.pdf. This is a Kleenest pilot concept, not an approved Four Seasons implementation._

## Offer

A low-burden guest-restroom experience layer that can begin without changing the guest environment and can add discreet QR touchpoints only where Four Seasons believes they improve service.

### Capabilities
- verified restroom / area profiles,
- guest condition signals,
- optional discreet QR,
- private service-recovery routing,
- operations dashboard,
- decision-ready pilot report.

The experience is meant to feel like service, not surveillance.

## Property-specific rationale

Reference facts used in the proposal:
- roughly 200 accommodations,
- roughly 20,000 sq. ft. of event/meeting space,
- up to roughly 900 reception guests in largest event configuration,
- approximately 12,000 sq. ft. spa,
- dining, rooftop, pool, and other non-room guest flows.

Reverify property facts from official sources before external reuse.

## Signal model

A single interaction can capture:
- exact restroom / area,
- timestamp and daypart,
- condition category,
- urgency,
- response event,
- after-state / recovery verification.

The goal is private operating data, not a public bathroom-rating campaign.

## Service-recovery loop

Guest/staff signal → triage and route → hotel team action → verified recovery → operational insight.

The basic pilot does not require PMS, guest-profile, clinical, or financial data.

## Recommended 60-90 day pilot

1. **No-signage baseline** — selected records, dashboard, guest-flow assumptions, baseline observations.
2. **Optional discreet QR** — 1-3 approved touchpoints only if the hotel wants them.
3. **Service loop** — route selected issues, track response, resolution, and proof.
4. **Decision report** — engagement, issue patterns, response time, experience value, expansion options.

## Value / pricing frame

- Founding hospitality pilot may be discounted or waived.
- Internal Enterprise starting floor: $499/month for complex deployments.
- A waived 90-day subscription at that floor represents $1,497 before onboarding/integration discounts.
- Scope expands based on locations/zones, users, integrations, reporting, support, and privacy/security requirements.

## End-of-pilot deliverables

- guest signal summary,
- issue map,
- response analysis,
- experience recommendations,
- scoped expansion quote,
- go / adjust / stop recommendation.

## Ask

A 20-30 minute scoping discussion with appropriate guest-experience, rooms, housekeeping, facilities, events, and marketing/PR stakeholders to choose:
- no-signage baseline,
- discreet QR test,
- service-recovery workflow test.

This is not:
- an endorsement request,
- a paid-restroom-access pitch,
- a replacement for existing hospitality systems,
- a request to change brand standards.
