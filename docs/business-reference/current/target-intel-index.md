## Common pilot loops

### Mobile workforce
Worker needs a stop → route-aware search → verified restroom/parking/amenity result → worker confirms useful find → Fleet sees aggregate signal → pilot optimizes support.

### Facilities / service
Issue/restroom need → Kleenest captures signal → supervisor assigns/triages → worker arrives/confirms → service verified → operator learns response patterns.

### Chamber / district
Local need → consumer discovery → facts verified → pilot businesses update profiles → district/chamber sees engagement → cohort expands.

### Founder / mentor
Assumption identified → interview/pilot test → evidence collected → metric reviewed → positioning/pricing adjusted → next milestone decided.
