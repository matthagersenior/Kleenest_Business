# Kleenest Cortex / SQ1 Validation Materials v9 — normalized reference

_Source artifacts: Kleenest_Cortex_SQ1_Materials_v9.pptx and .pdf._

## Framing

Kleenest is being re-underwritten around:
- consumer-first growth,
- conservative monetization,
- a Growth/Fleet field-operations wedge.

The detailed financial model is the canonical operating model for this generation. Core forecast excludes Enterprise and paid access.

## SQ1 ask

Use the program to:
- select the first customer wedge,
- select the first acquisition channel,
- pressure-test the Base-case assumptions,
- leave with one falsifiable 14-day experiment and a 10-week scoreboard.

## Validation questions

1. Do people use Kleenest repeatedly?
2. Do users create verified restroom observations?
3. Do businesses pay once local network value exists?
4. Do Growth/Fleet economics resonate with mobile-workforce employers?
5. Can the operations loop prove value?

## Mentor questions

1. **Wedge:** Which customer wedge and acquisition channel should be validated first?
2. **Pricing proof:** What evidence makes $20 Standard, $50/location Growth, $75 Fleet, and Enterprise credible without paid-access revenue?
3. **Disproof:** Which assumption should be attacked first—repeat use, verified observations, B2B conversion, employee-benefit economics, or FSM value?

## What not to overclaim

Do not say:
- paid restroom access is proven,
- Enterprise revenue is in the base forecast,
- seeded locations equal traction,
- Kleenest replaces full FSM/TMS/ELD systems.

Use:
- paid access is upside to test,
- Enterprise is priced internally but excluded until scoped,
- traction = active users, observations, pilots, and conversion,
- Kleenest is an affordable on-ramp to FSM-like functionality.
