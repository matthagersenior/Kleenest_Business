# Kleenest Target Intelligence — 37-Target Searchable Set

This folder converts the machine-readable target intelligence embedded in `Kleenest_Upgraded_Target_Materials_Pack.zip` into searchable repository text.

Source structure:
- 37 one-page target briefs
- 37 case-specific needs/resolution sheets
- 37 tailored PowerPoint loop decks
- `targets.json` machine-readable source
- master manual, high-priority deck and business-plan excerpts

The source pack remains the authoritative artifact for the exact generated collateral. These Markdown pages preserve the target-specific intelligence, pilot/ask, value proposition, business-plan fit, objections/risks, KPIs and loop.

## Use rule

Reverify external facts, current roles, current contact routes and organization status before outreach. Do not interpret a target packet as evidence that the target has agreed to participate.
