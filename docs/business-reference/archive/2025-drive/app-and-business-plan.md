I. Improved App Layout
Here's the refined app layout, focusing on the MVP and incorporating key suggestions:
1. Home Tab
* Purpose: Central hub for user engagement.
* Key Elements:
   * Header: App title/logo, user profile icon.
   * Announcements: Business promotions, app updates.
   * User Activity: Check-ins, reviews, community trends.
   * Nearby Services: Restroom suggestions.
   * Gamification: Points, badges, leaderboards.
   * Bottom Navigation: Home, Maps, Details, Profile, Business.
2. Maps Tab
* Purpose: Find restrooms.
* Key Elements:
   * Map View: User location, restroom markers.
   * Search Bar: Location/business search.
   * Filters:
      * MVP (Free): ADA accessible, baby changing.
      * Premium: Cleanliness rating, amenities, navigation.
   * Restroom Info: Callouts, optional list view.
   * Navigation (Premium): Route drawing, turn-by-turn.
   * Geofencing:(Phase 2) User-business interaction tracking.
   * Ads: Display for nearby businesses.
* Note: MVP prioritizes basic filters; premium features are clearly labeled.
3. Details Tab
* Purpose: Restroom information.
* Key Elements:
   * Restroom Header: Name, address.
   * Amenities List.
   * Ratings and Reviews.
   * Photos (Premium users can upload).
   * Business Info: Name, contact, response to reviews.
   * Ads: Targeted business ads.
   * Location Analytics: (For businesses) User data.
4. Profile Tab
* Purpose: User account.
* Key Elements:
   * User Information: Name, etc.
   * Settings: Preferences, subscriptions.
   * Achievements: Badges, points.
   * History: Visited restrooms, saved locations (premium).
5. Business Dashboard
* Purpose: Business tools.
* Key Elements:
   * Listing Management.
   * Analytics: User visits, feedback.
   * Ad Management: Create/edit ads.
   * QR Code Management.
   * Subscription Management.
   * Free vs. Premium Features.
