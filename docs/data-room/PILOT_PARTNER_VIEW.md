# Kleenest Pilot Partner / Customer View

Use this path when preparing for a business, association, employer, hospitality property, attraction, event, chamber, district, or civic pilot.

## 1. Start with the target-specific material

Use [TARGET_MATERIALS.md](./TARGET_MATERIALS.md) and the 37-target pack.

Each target should have:
1. one-page brief,
2. needs/resolution sheet,
3. tailored loop deck.

Do not start a meeting with the whole business plan unless the audience specifically needs it.

## 2. Use one outcome per meeting

Examples:
- permission to design a pilot,
- named internal champion,
- second meeting,
- 2–3 qualified introductions,
- permission to validate location/amenity data,
- agreement on KPIs,
- pilot confirmation.

## 3. Pilot design principles

A strong founding pilot should be:
- low burden,
- time bounded,
- measurable,
- non-exclusive,
- easy to stop,
- explicit about data/brand permissions,
- tied to a real operational or customer problem.

## 4. Consumer-facing pilots

Measure, as relevant:
- searches,
- successful amenity matches,
- useful-result rate,
- check-ins,
- verified observations,
- repeat usage,
- corrections/freshness,
- participating-business engagement,
- qualitative visitor/business feedback.

## 5. Fleet / mobile-workforce pilots

Measure, as relevant:
- employee activation,
- weekly active use,
- route/location searches,
- dispatch/task activity,
- arrival/service verification,
- issue-response time,
- supervisor satisfaction,
- employee satisfaction,
- willingness to continue/pay.

## 6. Business / hospitality pilots

Measure, as relevant:
- guest/customer discovery interactions,
- amenity searches,
- corrections,
- optional check-ins,
- partner feedback,
- repeat use,
- operational burden,
- continuation/expansion decision.

QR should be treated as an available verification/engagement tool, not a mandatory prerequisite for every pilot.

## 7. Brand and publicity

A pilot does not automatically grant permission to:
- use partner logos,
- issue press releases,
- call the organization a public partner,
- imply endorsement,
- use internal results publicly.

Obtain explicit permission.

## 8. Close

Every meeting should end with a concrete next step and owner.

Avoid “keep in touch.”
