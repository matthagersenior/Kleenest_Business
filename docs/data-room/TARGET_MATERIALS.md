See the full target list at:
- [37-Target Materials Manifest](../business-reference/validation/target-materials-manifest.md)
- [Target Intel Index](../business-reference/current/target-intel-index.md)

## Required target packet

For each target, maintain:

1. **Target brief**
   - organization/person context,
   - reason Kleenest is relevant,
   - likely needs,
   - single ask,
   - likely objection,
   - proof points,
   - KPI suggestions.

2. **Needs → resolution sheet**
   - target-specific operational/customer problem,
   - Kleenest capability,
   - measurable outcome,
   - smallest testable pilot.

3. **Tailored loop deck**
   - target-specific five-slide story,
   - not a generic feature dump.

4. **Current status**
   - not contacted,
   - outreach sent,
   - replied,
   - meeting scheduled,
   - discovery complete,
   - pilot-design,
   - pilot confirmed,
   - active,
   - declined / paused.

5. **Evidence log**
   - email/thread,
   - meeting notes,
   - named contact,
   - commitments,
   - follow-up date,
   - permission/publicity restrictions.

## Rule

Do not reuse a generic deck where a target-specific one exists.

If the target's status materially changes, update the brief and meeting prep before the next interaction.
