# Kleenest Business Data Room

This directory is the operating index for Kleenest business, pilot, fundraising, market, financial, and diligence material.

It is intentionally separate from `docs/business-reference/`:

- **`business-reference/`** preserves and catalogs source material, version history, research, workshops, and archives.
- **`data-room/`** tells a founder, mentor, pilot partner, grant reviewer, angel, or diligence reviewer what to read **now**, in what order, and which material is current versus historical.

## Core operating principle

Kleenest must distinguish **infrastructure/data coverage** from **traction**.

Location records, seeded data, product surfaces, and ingestion breadth are assets and capability evidence. They are not customers, active users, pilot conversions, revenue, or validated demand unless a current source explicitly supports that claim.

## Data-room audiences

### Investor / grant / mentor
Use the investor view, current business plan, current financial model, current market evidence, product/demo proof, and traction/pilot evidence.

### Pilot partner / customer
Use the pilot-partner view, relevant target brief, relevant needs/resolution sheet, target-specific loop deck, current pilot scope, and only the proof points relevant to that organization.

### Internal founder operations
Use the full reference corpus, validation history, workshop materials, opportunity readiness system, and target pack manifests.
