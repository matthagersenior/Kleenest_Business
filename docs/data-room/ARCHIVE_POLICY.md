# Kleenest Business Data Room — Archive Policy

## Purpose

Kleenest has accumulated multiple generations of business plans, decks, financials, outreach plans, workshop materials, pilot packs, and prototypes. The archive is valuable, but only if old assumptions cannot silently leak into current materials.

## Current material

The `docs/business-reference/current/` directory is the default company-wide source.

A later target-specific document may override current company-wide material only for that target and only where the newer target document clearly changes the offer or framing.

## Historical material

Examples:
- v3 All-New direction/pitch/business-plan pack,
- v4 Consumer-First meeting pack,
- v5 business-plan set,
- v6 redone business plan/outreach,
- v7 business-plan/outreach/financial projection set,
- v8 SQ1/Four Seasons/financial variants,
- early one-page pitch,
- sales-ready HTML,
- QR/Premium/Business prototype lineage.

Historical material may be used to:
- understand strategic evolution,
- recover prior ideas,
- explain why current positioning changed,
- compare forecasts,
- trace product/business provenance.

It must not be quoted as present-day truth without checking the current set.

## External references

External references—competitor research, association applications, public program descriptions, studies—must be labeled external and dated.

Time-sensitive external claims must be reverified before external/public reuse.

## Binary originals

Binary originals should remain preserved in their source system when they cannot be stored directly in this Git workflow.

The repo should retain:
- exact filename,
- version,
- date,
- source system,
- description,
- relationship to current material.

## Duplicate rule

If the same file appears in Library, Drive, a ZIP pack, and email:
- preserve one preferred source identity,
- record duplicates where useful for provenance,
- do not treat duplicates as separate evidence.

## Conflict rule

Never delete a historical source merely because it conflicts with the current strategy. Archive it and make precedence explicit.
